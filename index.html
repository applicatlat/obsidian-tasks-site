Obsidian Google Tasks Integration

Manage your Google Tasks directly from Obsidian.

This project provides an integration between Obsidian and Google Tasks. It allows users to access and manage their Google Tasks while working inside the Obsidian note-taking environment.

How it works

The integration uses Google's official Google Tasks API to access the Google Tasks associated with the user's Google Account.

Access is granted only after the user signs in with Google and explicitly authorizes the application.

Google Account Data

The application accesses Google Tasks data only for the purpose of providing Google Tasks functionality inside Obsidian. Google Account data is not sold or used for advertising.

Important: This project is an independent application and is not affiliated with or endorsed by Google.
